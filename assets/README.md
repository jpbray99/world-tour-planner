# assets

## redeye.jpg

The photo shown on a calendar night marked **Red-eye** (a lie-flat cabin at night).

Drop the image here as exactly `redeye.jpg` and it appears on every red-eye night with no
code change. Until then the block falls back to a purple night-cabin gradient with the
"Red-eye" label, so a missing file degrades to a plain label rather than a broken image box.

Keep it landscape and reasonably small (roughly 900px wide is plenty) -- it renders as a
thin strip about 90px tall.
